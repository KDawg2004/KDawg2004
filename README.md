## About Me

I'm an undergraduate researcher focused on the intersection of hardware and machine learning.

Currently I'm building Python simulation frameworks that model mixed **memristor/memcapacitor crossbar arrays**, allowing neural networks to be evaluated under realistic hardware non-idealities including:

- Device variability
- Endurance degradation
- Parasitic wire resistance
- Analog weight programming

My long-term interests include:

- Neuromorphic Computing
- Computer Architecture
- Embedded Systems
- Hardware Acceleration
- Operating Systems
- Algorithms & Theory
